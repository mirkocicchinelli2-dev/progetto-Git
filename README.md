## Progetto Hello World

Nome: Mirko
Cognome: Cicchinelli
Classe: 5E

## Descrizione
Il programma visualizza il messaggio Hello World.


## Come eseguire il programma
Installare Python sul computer.
Aprire il terminale nella cartella del progetto.
Eseguire il comando:
   py hello.py
Il programma visualizzerà:
   Hello World
   Il mio primo progetto con Git!
